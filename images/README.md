# images

LPが読み込む画像です。差し替える場合は同じファイル名で上書きしてください。

| ファイル名 | 表示箇所 | 現在のサイズ |
| --- | --- | --- |
| `solution.jpg` | SOLUTION のInstagram投稿風カード（4:3） | 1400×1050 / 130KB |
| `gm.jpg` | MESSAGE FROM GM の人物写真（4:3で表示） | 720×720 / 64KB |

元の写真（5881×3921・3.2MB）から、表示サイズに合わせて書き出しています。
そのまま載せると読み込みが遅くなるため、Web用に軽量化しています。

参考LPのスクリーンショットは `reference/buddica-lp/` にあります。
