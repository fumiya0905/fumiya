# images

LPが読み込む画像です。差し替える場合は同じファイル名で上書きしてください。
未設置のファイルは自動的に非表示になり、レイアウトは崩れません。

| ファイル名 | 表示箇所 | 推奨サイズ | 状態 |
| --- | --- | --- | --- |
| `gm.jpg` | MESSAGE FROM GM の人物写真（円形） | 正方形・600px以上 | 設置済み |
| `account-1.jpg` | RESULTS：@makoto__miyamoto のアイコン | 正方形・200px以上 | 未設置 |
| `account-2.jpg` | RESULTS：@kazuhito__kouno のアイコン | 正方形・200px以上 | 未設置 |
| `account-3.jpg` | RESULTS：@shimada.info のアイコン | 正方形・200px以上 | 未設置 |

アイコンは円形に切り抜かれるため、顔や被写体が中央にある正方形の画像が適しています。
未設置の間はゴールドの円が表示されます。

参考LPのスクリーンショットは `reference/buddica-lp/` にあります。
