# images

LPが読み込む画像です。差し替える場合は同じファイル名で上書きしてください。
未設置のファイルは自動的に非表示になり、レイアウトは崩れません。

| ファイル名 | 表示箇所 | 現在のサイズ |
| --- | --- | --- |
| `gm.jpg` | MESSAGE FROM GM の人物写真（円形） | 720×720 |
| `account-1.jpg` | RESULTS：@makoto__miyamoto のアイコン | 320×320 |
| `account-2.jpg` | RESULTS：@kazuhito__kouno のアイコン | 320×320 |
| `account-3.jpg` | RESULTS：@shimada.info のアイコン | 320×320 |

アカウントのアイコンは、いただいたInstagramプロフィール画面のスクリーンショットから
円の部分だけを検出して切り出し、Web用に軽量化しています。
差し替える場合はスクリーンショットのままでも構いません（こちらで同じ処理をします）。

参考LPのスクリーンショットは `reference/buddica-lp/` にあります。
