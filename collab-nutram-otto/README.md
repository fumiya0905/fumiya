# ニュートラム × OTTO コラボLP

`index.html` 1ファイル＋ `images/` で動くLPです（CSSはページ内、JSなし、外部依存はGoogle Fontsのみ）。
CSSはすべて `.nxo` の中に閉じているため、BASEのテーマに埋め込んでも既存のスタイルとぶつかりにくい作りです。

## 構成
デザインは GREEN SPOON（green-spoon.jp）のスクリーンショットを参考にしています。
配色は白背景で、ニュートラムに関わる部分を薄い青、OTTOに関わる部分をオレンジにしています。ヘッダー・締め・フッターはオレンジです。

1. お知らせ帯＋ヘッダー（左：ページ内リンク／中央：ロゴ／右：購入ボタン）
2. メインビジュアル — 全面写真＋指定の文章＋下端に大きなロゴ
3. Our Story — 3カラム（見出し／写真／本文）＋両ブランド紹介
4. Features — トッピングの3つの利点（スマホは横スクロール）
5. Perfect Pair — T27 / T28 / T29 のタブ切り替え＋OTTOの新鮮さと水分＋まとめの帯
6. How to use — オレンジの帯、3ステップ＋右側に縦長写真
7. Products — セットのカード（緑の帯・価格・購入ボタン）
8. 締めのコピー＋ボタン
9. 濃い色のフッター＋大きなロゴ
10. 画面下に追従する「セットを見る」ボタン（MV・Products・フッターでは自動で隠れます）

JSは末尾に約40行（タブ切り替えと追従ボタン）。JSが動かない環境では T27〜T29 が縦に全部並びます。

「ストレスケア」「免疫ケア」「筋肉ケア」「胃腸ケア」「体の中から健康を守る」は機能をうたう表現です。
根拠（メーカーの公式表現・資料）が無いまま使うと、景品表示法の優良誤認を問われるおそれがあります。
両社が公式に使っている表現の範囲に収まっているか、公開前に確認してください。

## BASEへの組み込み
BASEは独立したHTMLファイルをそのままアップロードする仕組みがないため、次のどちらかになります。

- **A. HTML編集App でテーマに組み込む**：`<style>` の中身をテーマのCSSへ、`<div class="nxo">〜</div>` をLP用ページのテンプレートへ貼り付け。画像はBASEに上げたURLへ `src` を書き換え。
- **B. 別ドメイン／サブドメインで公開し、BASEからリンク**：このフォルダをそのまま置くだけで動きます。購入ボタンだけBASEの商品ページへ。

どちらが使えるかは利用中のBASEプラン・テーマ次第なので、組み込み先の確認をお願いします。
